# FocusX — نسخه اولیه اندروید

## قابلیت‌ها
- محدودیت مستقل ۲۰ دقیقه در روز برای Instagram، TikTok و YouTube
- پس از پایان سهمیه هر برنامه، صفحه قفل تا نیمه‌شب محلی نمایش داده می‌شود
- شمارش معکوس تا ساعت ۰۰:۰۰

## ساخت APK
1. Android Studio را نصب و این پوشه را با گزینه Open باز کن.
2. اجازه بده Gradle Sync کامل شود و Android SDK 35 نصب باشد.
3. از منوی Build گزینه Build APK(s) را بزن.
4. APK خروجی معمولاً در `app/build/outputs/apk/debug/app-debug.apk` قرار می‌گیرد.

## راه‌اندازی روی گوشی
1. FocusX را نصب و باز کن.
2. دکمه «فعال‌سازی دسترسی آمار استفاده» را بزن و دسترسی Usage access را برای FocusX روشن کن.
3. به FocusX برگرد، دکمه Accessibility را بزن و سرویس FocusX App Blocker را روشن کن.
4. در MIUI از تنظیمات باتری، FocusX را روی No restrictions بگذار و Autostart را فعال کن.

## نکات مهم
- این نسخه از UsageStats و Accessibility استفاده می‌کند؛ بدون این دو مجوز نمی‌تواند برنامه‌ها را مسدود کند.
- قفل نرم‌افزاری است و با خاموش‌کردن سرویس Accessibility یا حذف FocusX قابل دور زدن است.
- بعضی نسخه‌های MIUI ممکن است سرویس پس‌زمینه را متوقف کنند؛ تنظیمات باتری و اجرای خودکار مهم‌اند.
- برای نصب روی گوشی‌های دیگر یا انتشار عمومی، بهتر است رفتار سرویس و سازگاری نسخه‌های مختلف اندروید جداگانه آزمایش شود.
